# Guide de démarrage rapide

Suivez ce parcours pour réaliser votre premier cycle Voix du Client.

1. Configurez la structure de l'organisation.
2. Ajoutez les utilisateurs et leurs accès.
3. Configurez le cadre VOC.
4. Ajoutez ou importez les contacts.
5. Préparez la bibliothèque de questions.
6. Créez l'enquête et sélectionnez les répondants.
7. Publiez l'enquête.
8. Suivez les réponses.
9. Analysez les enseignements.
10. Créez et suivez les actions d'amélioration.
