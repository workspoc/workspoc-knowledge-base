# Configuring Respondents

Build the survey audience from accurate, permissioned contacts.

1. Define eligibility and exclusion rules.
2. Filter contacts using classification and relevant attributes.
3. Review audience size and segment representation.
4. Inspect a sample of included and excluded contacts.
5. Confirm duplicate, opt-out and invalid-address handling.

See [Managing Contacts](./managing-contacts.md) for data preparation.
