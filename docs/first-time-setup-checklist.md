# First-Time Setup Checklist

Complete these checks before the first survey:

- [ ] Programme sponsor, administrator and survey owner confirmed
- [ ] Operating Year and reporting structure configured
- [ ] User access reviewed
- [ ] Pillars, Domains and Practices approved
- [ ] Contact data imported and validated
- [ ] Questions and Topic Templates prepared
- [ ] Audience, invitation and dates approved
- [ ] Test response completed
- [ ] Insight review and action process scheduled

Follow the [Quick Start Guide](./quick-start-guide) for the complete journey.
