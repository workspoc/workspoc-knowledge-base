# Frequently Asked Questions

Quick answers to common questions about configuring and using workSPOC Voice.

<div className="faq">
<details><summary>What should I configure before creating my first survey?</summary><p>Set up the relevant organisation structure, users and permissions, VOC framework, contacts, approved questions and survey governance.</p></details>
<details><summary>Can I reuse questions across surveys?</summary><p>Yes. Use approved questions from the Question Repository to improve consistency and comparison.</p></details>
<details><summary>What is the difference between a Pillar, Domain and Practice?</summary><p>A Pillar is a strategic area, a Domain is a measurable area within it, and a Practice is a specific capability or behaviour.</p></details>
<details><summary>Can I import customer contacts?</summary><p>Yes. Import prepared contact data, review validation messages and resolve duplicates before using it for an audience.</p></details>
<details><summary>Can different surveys use different customer groups?</summary><p>Yes. Respondent audiences can use classifications and other permitted contact attributes.</p></details>
<details><summary>Can a survey be changed after it is published?</summary><p>Measurement changes may be restricted to protect response integrity. Review and test carefully before publication.</p></details>
<details><summary>How do I monitor survey completion?</summary><p>Open the survey Progress view to review invited, delivered, opened, started and completed statuses.</p></details>
<details><summary>How do insights become improvement actions?</summary><p>Validate the evidence, create an action, assign an owner and define a due date and measurable outcome.</p></details>
<details><summary>Who can create or manage users?</summary><p>Only users with the appropriate administrative permission should add, change or disable users.</p></details>
<details><summary>Where can I find previously created questions?</summary><p>Search the Question Repository and check filters such as status, category and framework mapping.</p></details>
</div>
