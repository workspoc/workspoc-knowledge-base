# Question Repository

The Question Repository is the central, reusable library for survey questions.

## Why this matters

Reusing validated wording improves respondent understanding, makes results comparable across surveys and reduces duplicated design work.

## How it works

Questions can be searched and filtered by status, category, response format, framework mapping and topic. Approved questions can be reused in multiple surveys without rebuilding them.

## Step-by-step

1. Open **Surveys → Question Repository**.
2. Search before creating a new question.
3. Filter by category, topic or Pillar, Domain and Practice.
4. Review wording, response scale and usage notes.
5. Create or update content through the agreed approval process.
6. Select approved questions while designing a survey.

## Example

An existing relationship question uses the organisation's standard five-point scale. Reusing it in a regional survey preserves trend comparability and avoids introducing a subtly different measure.

## Best practices

- Give each question one clear purpose.
- Avoid combining two ideas in one question.
- Preserve approved wording when trend comparison matters.
- Retire duplicates without removing historic survey evidence.

## Frequently asked questions

**Can I reuse questions across surveys?** Yes—that is a core purpose of the repository.

**Where can I find previously created questions?** Search the Question Repository and adjust status or category filters if necessary.
