# User Roles & Access

Roles group permissions for common responsibilities. Access may also be limited by organisational scope.

## Best practices

- Give users only the access required for their work.
- Separate administration from ordinary survey tasks where practical.
- Review privileged access and inactive users regularly.
- Update access when responsibilities change.

See [Managing Users](./managing-users.md) for the user lifecycle.
